Textual elements provide the semantic structure that organizes written information. This section explores document headings, inline semantics, quotations, annotations and related content models.

Phrasing & Text

This paragraph contains a standard <a> for links.

Use <strong> for importance, <b> for stylistic offset, <em> for emphasis, and <i> for an alternate voice.

Text can be highlighted with <mark>, deleted <del>, inserted <ins>, or no longer accurate <s>.

Subscript <sub> & Superscript <sup>: H2O and E = mc2.

Use <abbr> for abbreviations, like HTML, and <q> for short inline quotes.

Use <u> for unarticulated annotations, like spellling mistakes.
